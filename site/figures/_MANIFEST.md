# Figures

Generated by `python scripts/make_figures.py` (this file is underscore-prefixed so Quarto does not render it) from `solutions/` with fixed PRNG keys.
One line per file: name, then a one-sentence description suitable as alt text. Trained
models and multi-chain runs are cached in `_cache/` (safe to delete; regenerating takes
about two minutes).
